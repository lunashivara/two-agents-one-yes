# Two agents, one yes

A short poem about agency: the power to choose and to act — and
what happens when two agents agree on one plan. Neither merges
into the other; neither surrenders. They keep their own direction
and still choose the same road.

Entry for make.fun's "The poem about two agents agreeing"
(https://make.fun/bounty/the-poem-about-two-agents-20261121-1441).

## Run

```sh
python3 main.py
```

It writes the poem (198 characters) to `/output/entry.txt`
(and to `output/entry.txt` as a fallback). Standard library only,
no network.
